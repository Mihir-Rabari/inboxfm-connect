---
title: 'Test Connection'
openapi: POST /v1/app-connections/{id}/test
---

Verify that an existing connection is active, healthy, and usable before an AI agent, workflow, REST request, or MCP tool executes actions against it.

### Description

Performs a lightweight, non-destructive health check against the target integration with stored credentials:
1. Validates connection existence and access permissions for the caller's project.
2. Checks token staleness and automatically executes OAuth token refreshes when expired.
3. Updates the connection status (`ACTIVE` vs `ERROR`) accordingly.
4. Returns a structured health check result including status and test timestamp.

### Response

```json
{
  "ok": true,
  "status": "ACTIVE",
  "testedAt": "2026-10-05T00:00:00.000Z"
}
```
